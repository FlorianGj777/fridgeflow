# FridgeFlow — Design Context

## Design Context

### Users
Usage personnel exclusif (un seul utilisateur : le développeur lui-même). Contexte : consulter rapidement l'app en cuisine ou au supermarché, souvent d'une seule main. Le besoin est de faire les choses vite — ajouter un repas, cocher un article, vérifier le frigo — sans jamais se perdre dans une interface.

### Brand Personality
**Trois mots** : efficient · chaleureuse · structurée

C'est un carnet de cuisine numérique, pas une app grand public. Il doit donner la sensation d'un espace bien organisé : comme un workspace Notion qu'on aurait configuré soi-même pour gérer sa semaine alimentaire.

### Aesthetic Direction
- **Référence principale** : Notion — clarté des blocs, hiérarchie typographique nette, couleur utilisée avec parcimonie, fond presque blanc avec une légère chaleur
- **Thème** : Clair (light mode) par défaut, dark mode supporté
- **Couleur** : Violet primaire conservé mais utilisé en accent rare — les neutres sont tintés très légèrement vers le violet pour une cohérence subconsciente
- **Typographie** : Bricolage Grotesque — grotesque humaniste avec de la personnalité, chaleureux sans être rond/enfantin
- **Formes** : Radius réduit (8px) — plus de cards ultra-arrondies, on préfère la géométrie nette de Notion
- **Ombres** : Quasi absentes sur les cards — bordure fine à la place

### Design Principles
1. **Densité utile** : L'écran est petit (430px max). Chaque pixel doit servir une information ou une action. Pas de décoration pour décorer.
2. **La couleur est un signal** : Le violet primaire n'apparaît que pour les actions actives, les états sélectionnés, les éléments importants. Les neutres dominent.
3. **Hiérarchie par taille et poids, pas par couleur** : Titres nets, sous-titres lisibles, labels discrets — le contraste de taille crée la structure.
4. **Efficacité avant élégance** : Les interactions doivent être rapides. Pas de modales superflues, pas d'animations qui font attendre.
5. **Cohérence sans rigidité** : Le design est cohérent mais laisse de la respiration — certains espaces sont intentionnellement plus généreux que d'autres pour créer du rythme.
